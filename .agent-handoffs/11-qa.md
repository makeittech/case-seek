## Issues found & fixed

### Broken assets / console errors
1. **Missing PWA icons** — `manifest.webmanifest` declared `icon-192.png`/`icon-512.png`; neither existed (404, install broken). Rendered both from the favicon mark (same geometry/colors), verified served 200 from the built app.
2. **`ui-board-string.webp` defective** — the evidence-board red thread had max alpha 91/255 and pure-black RGB: a near-invisible smudge. Regenerated as a proper tileable twisted red cord (alpha 0–255, seam-matched edges, passes the audit's placeholder/alpha heuristics). Not yet consumed by code — but it now honors its manifest contract.
3. **Zero console errors at runtime** — new `e2e/console-hygiene.spec.ts` drives a first-beat pass in all 3 languages and fails on any console error, pageerror, 4xx, or failed request. Clean in de/es/it.

### Tooling bug (destructive)
4. **`generate-assets-manifest.mjs` clobbered hand-edited statuses** — any run rewrote `content/assets-manifest.json` with `status/qaStatus: pending`, wiping production bookkeeping (78 hand-set `qaStatus: passed` entries were lost this way; restored from git history). The generator now preserves existing `status`/`qaStatus` by assetId and supports a non-destructive `--check` mode.
5. **736 stale `status: pending` entries** — every generated file exists and decodes; flipped to `generated` (the audit now enforces this). `qaStatus` was left as authored (78 passed / 658 pending); the concurrent art agent has since completed its own visual audit and marked all 736 passed (`1db93c5`).

### Language QA (independent second pass)
- Re-reviewed all 207 rows × 3 languages in `tools/gen/vocab-data.mjs` (articles, plurals, description phrases), the derived pack articles for the phonologically hard cases (l'ancora→le ancore, lo sgabello/straccio/stampino/spago/schedario, el ancla→las anclas, das Band/die Leiter/der Anhänger, pluralia tantum), the 69-token bank, 12+12 vendor calls/signage per language, and all dialogue/story text for leaks. One genuine error:
- **Fixed: de `fits-perfectly` token** — «wie die Faust aufs Auge» natively means "doesn't fit at all" (only ironically the opposite); glossed flatly as *fits perfectly* it would teach learners wrong. Now «wie angegossen». Packs regenerated from source; validator/tests green.
- Non-issues verified deliberately: "Nachtigall" in English dialogue is canon (STORY_BIBLE §5 alias, glossed via the L1 nightingale garnish); es «Buenas noches» as evening greeting; truncated proverbs («Sin prisa, sin pausa», «Chi va piano va sano») are within the ≤5-word L2 limit by design.

### Accessibility (axe-core, blocking = critical+serious)
6. **Notebook tablist (critical)** — the close button sat inside `role="tablist"`; only tabs may be children. Moved it out; tabs now carry `aria-controls` and the body is a labelled `role="tabpanel"`.
7. **Find-list chips (critical)** — tray is `role="list"` but chips had no role; chips now `role="listitem"`.
8. **Page zoom disabled (WCAG 1.4.4)** — `maximum-scale=1.0, user-scalable=no` removed from the viewport meta. Canvas gestures are unaffected (`touch-action: none` on the canvas element).
9. New `e2e/a11y.spec.ts` (axe-core walk: title → onboarding → beat → map → notebook → search) keeps this enforced. It runs under `reducedMotion: 'reduce'` — without it axe snapshots mid-entrance-fade and reports false contrast failures; settled colors all pass (paper-dim on dark ≈12:1, ink on gold ≈10:1).
